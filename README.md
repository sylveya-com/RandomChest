# RandomChest

Randomized loot chest plugin for Spigot

## » About

Adds loot chests with configurable chest types, randomized loot, and automatic refills. Each chest type has its own loot settings, item properties, respawn delays, and interaction rules.

## » Commands

* `/randomchest select <type>` — Select a chest type
* `/randomchest unselect` — Clear the current selection
* `/randomchest reload` — Reload configuration and database
* `/randomchest restore` — Restore registered chests

## » Usage

* **Register:** Hold `GUNPOWDER` and right-click a chest in creative mode
* **Remove:** Hold `SUGAR` and right-click a registered chest in creative mode
* **Unselect:** Run `/randomchest unselect`

Registered chests generate random loot when opened and refill after their configured respawn delay.

## » Configuration

Chest types support configurable loot tables, item amounts, enchantments, potion effects, custom names and lore, player skulls, durability ranges, and respawn delays.

Additional options control whether players can destroy registered chests.

Enjoy RandomChest!
